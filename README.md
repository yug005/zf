## <img src="https://media.giphy.com/media/iY8CRBdQXODJSCERIr/giphy.gif" width="28"> &nbsp; What is Zer0Friction?

> **Zer0Friction** is a full-stack, production-grade **uptime monitoring** and **autonomous security intelligence** platform. It watches your websites, APIs, SSL certificates, and DNS records around the clock — and when something breaks, you know in milliseconds, not minutes.

<table>
<tr>
<td width="50%">

### 🎯 &nbsp; Core Platform
- ⚡ **Real-time uptime monitoring** with sub-second check intervals
- 🔔 **Instant alerts** via Email, Slack & Discord
- 📊 **Response-time analytics** & historical dashboards
- 🔒 **SSL/TLS certificate** expiry monitoring
- 🌐 **DNS record** change tracking
- 📋 **Public status pages** for your users
- 🚨 **Incident management** with auto-detection
- 🔄 **Deploy tracking** with GitHub CI/CD integration
- 💳 **Billing & subscriptions** via Razorpay

</td>
<td width="50%">

### 🛡️ &nbsp; Security Engine
- 🤖 **Autonomous decision engine** for risk-based scan planning
- 🕸️ **Exploit chain analysis** with attack-path graphs
- 💉 **Injection & deserialization** testing
- 🔑 **Credential auditing** & breach exposure checks
- 🏗️ **Cloud infrastructure** probing
- 🧠 **Continuous learning** across scan cycles
- 🏃 **Race condition** detection engine
- 🔍 **Intelligent recon** & asset discovery
- 📝 **Executive security reports** with remediation guidance

> **Prerequisites:** Node.js 22+ · npm 10+ · Docker Desktop

<table>
<tr>
<td>

### 1️⃣ &nbsp; Clone & Configure

```powershell
git clone https://github.com/yug005/zf.git
cd zf
Copy-Item .env.example .env
```

### 2️⃣ &nbsp; Install Dependencies

```powershell
npm install                        # Backend
```

<summary><h2>⌨️ &nbsp; CLI — <code>zf</code> Command Line Tool</h2></summary>

<br/>

Zer0Friction ships with a powerful CLI for managing your monitoring infrastructure from the terminal.

### Build & Install

```powershell
npm run cli:build              # Compile TypeScript
npm run cli:link               # Install globally as `zf`
```

### Usage

```powershell
zf help                        # Show all commands
zf doctor                      # Verify system requirements
zf init                        # Initialize project config
zf projects create --interactive
zf monitors create --interactive
zf monitors list
```

### Shell Completions

```powershell
# PowerShell
zf completion powershell | Out-String | Add-Content $PROFILE

# Bash
zf completion bash >> ~/.bashrc

# Zsh
zf completion zsh >> ~/.zshrc

# Fish
zf completion fish > ~/.config/fish/completions/zf.fish
```

### Package & Distribute

```powershell
npm run cli:pack               # Creates tarball
```

<summary><h2>🔄 &nbsp; GitHub Deploy Automation</h2></summary>

<br/>

Automatically track deployments from your CI/CD pipeline into Zer0Friction's incident correlation engine.

### How It Works

```
Push to main → GitHub Action fires → POST /api/v1/changes/ingest/deploy
                                            ↓
                               Zer0Friction stores deploy event
                                            ↓
                          Monitor fails near deploy time?
                                            ↓
                            ⚡ Auto-correlates as likely trigger
```

### Setup

**1. Add Repository Secrets:**

| Secret | Description |
|:---|:---|
| `ZER0FRICTION_BACKEND_URL` | Your API base URL |
| `ZER0FRICTION_API_KEY` | API key from dashboard |
| `ZER0FRICTION_PROJECT_SLUG` | Target project slug |

**2. Optional Variables:**

| Variable | Description |
|:---|:---|
| `ZER0FRICTION_SERVICE_NAME` | Service identifier |
| `ZER0FRICTION_ENVIRONMENT` | Environment label |

**3.** Use the included workflow: [`.github/workflows/report-zer0friction-deploy.yml`](.github/workflows/report-zer0friction-deploy.yml)

> 📖 Full guide: [GITHUB_DEPLOY_AUTOMATION.md](GITHUB_DEPLOY_AUTOMATION.md)

</details>

<details>
<summary><h2>🛠️ &nbsp; Troubleshooting</h2></summary>

<br/>

| Problem | Solution |
|:---|:---|
| `npm run dev` fails | Ensure ports `3000`, `5173`, `5432`, `6379` are free |
| Database connection error | Run `npm run infra:up` first — PostgreSQL & Redis must be running |
| Prisma migration fails | Check `DATABASE_URL` in `.env` matches `postgres:yugYUG123` |
| Frontend won't load | Run `npm --prefix frontend install` separately |
| Docker won't start | Make sure Docker Desktop is running |
| Billing features missing | Set `ADMIN_EMAIL` + `ADMIN_PASSWORD` in `.env` for local dev |
